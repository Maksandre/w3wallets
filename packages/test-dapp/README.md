# W3Wallets Test DApp

Test dApp for the w3wallets e2e suite: ERC-20 and ERC-721 contracts on a local Anvil chain, plus a Polkadot page for Substrate wallets.

Stack: Vite + React 19 SPA, wagmi 3 + viem, TanStack Query and Router, Tailwind CSS 4, polkadot-api, Foundry.

## Quick start

From the repo root:

```bash
yarn install
yarn start:dapp   # anvil :8545, deploys contracts, serves the dApp on :3001
```

Open http://localhost:3001 (EVM) or http://localhost:3001/polkadot (Substrate).

## Step by step

```bash
yarn start:anvil                              # 1. local chain on :8545
yarn deploy                                   # 2. deploy contracts
yarn workspace @w3wallets/test-dapp build     # 3. build the SPA
yarn workspace @w3wallets/test-dapp start     # 4. serve it on :3001
```

Contracts are deployed from Anvil's first account to deterministic addresses:

- TestToken (ERC-20): `0x5FbDB2315678afecb367f032d93F642f64180aa3`
- TestNFT (ERC-721): `0xe7f1725E7734CE288F8367e1Bb143E90bb3F0512`

## Wallets

EVM wallets are discovered through EIP-6963, so MetaMask appears as its own **MetaMask** button. Connecting asks the wallet to connect and then to add/switch to Anvil (chain 31337).

## Contracts and typed ABIs

- `contracts/TestToken.sol`: ERC-20 with public `mint()` and `burnAll()`
- `contracts/TestNFT.sol`: ERC-721 with public `mint(address, uri)`

`src/generated.ts` holds the typed ABIs and addresses, generated by `@wagmi/cli` from the Foundry build. Regenerate it after changing a contract or a deployment address:

```bash
yarn workspace @w3wallets/test-dapp generate
```

## Test contract

The e2e tests in `packages/w3wallets/tests` select elements by `data-testid` and by wallet button names (`MetaMask`, `Polkadot.js`). Keep them stable when changing the UI.

## Scripts

| Script | Description |
|--------|-------------|
| `dev` | Vite dev server on :3001 |
| `build` | Type-check and build the production bundle |
| `start` | Serve the production bundle on :3001 |
| `typecheck` | `tsc -b` |
| `lint` | ESLint |
| `generate` | Regenerate `src/generated.ts` from the contracts |
| `compile` | `forge build` |
| `anvil` | Start a local Anvil node |
| `deploy` | Deploy contracts to Anvil |
| `start:all` | Anvil + deploy + build + serve |
